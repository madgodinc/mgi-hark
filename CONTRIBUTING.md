# Contributing

Issues and pull requests are welcome.

- Code and comments in English. The app's UI text stays Russian; that is the audience.
- `README.md` has the build and check steps.
- `cargo clippy` in `src-tauri` should stay clean.
- The gaming glossary is maintained in a private repository and is not part of pull requests; `server/glossary.example.json` is the format to build and test against.
- Versions and releases are cut by MGI. Don't change version fields or `docs/history.json` in a pull request.

For a change bigger than a fix, open an issue first so the direction is agreed on before the work.
